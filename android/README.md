# Spencers Enterprices Android demo

This repository builds a debug-installable Android APK through GitHub Actions.

The APK is a Capacitor Android shell that opens the hosted Spencers Enterprices customer app. It requires an internet connection. Customer demo data remains in the hosted app's browser storage; this is not an offline-native application.

## Get the APK

1. Open the repository's **Actions** tab.
2. Select **Build Spencers Enterprices Android APK**.
3. Open the latest successful run.
4. Download **Spencers Enterprices-Android-Demo-APK** under Artifacts.
5. Extract the ZIP and install `app-debug.apk` on an Android device.

This is a demo/debug APK, not a Play Store-signed release.
